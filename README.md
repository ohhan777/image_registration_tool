# Image Registration Tool

이미지 정합을 위한 GUI 도구로, 두 개의 이미지에서 대응점을 선택하고 관리할 수 있는 PyQt6 기반 애플리케이션입니다.

## 기능

### 주요 기능
- **이미지 로드**: PNG, JPG, BMP, GIF, TIF 형식 지원
- **대응점 선택**: 마우스 클릭으로 좌표점 추가/수정/삭제
- **좌표 관리**: 번호 라벨 수정, 개별/전체 삭제 기능
- **확대/축소**: 마우스 휠 또는 툴바 버튼으로 이미지 확대/축소
- **패닝**: Ctrl+드래그 또는 중간 마우스 버튼으로 이미지 이동
- **실행 취소**: Ctrl+Z로 마지막 작업 취소 (최대 50단계)
- **좌표 저장/로드**: 텍스트 파일 형식으로 좌표 데이터 관리
- **이미지 저장**: 좌표가 표시된 이미지 저장
- **정합/오버레이**: 두 창의 정합점으로 호모그래피를 추정해 겹친 결과를 확인
- **실시간 정합(Live)**: 정합점을 찍는 즉시 오버레이가 갱신됨
- **마커 표시 설정**: 정합점 마커/번호의 색상·크기 조절 (줌과 무관하게 항상 같은 크기)

### 실시간 정합 (Live)

창 2 툴바의 **정합 버튼 옆 `Live` 토글**을 켜면 정합 결과를 실시간으로 보여주는
오버레이 창이 열린다. 정합점 쌍이 늘어날수록 변환 모델의 자유도가 함께 올라간다.

| 정합점 쌍 | 사용하는 모델 |
|---|---|
| 0쌍 | 배율을 맞추고(비율 유지) 두 영상의 중앙을 겹침 |
| 1쌍 | 평행이동 |
| 2쌍 | 유사변환(회전 + 등방 스케일 + 평행이동) |
| 3쌍 | 어파인 |
| 4쌍 | 최소제곱 호모그래피 |
| 5쌍 이상 | RANSAC 호모그래피 (`정합` 버튼과 동일) |

양쪽 창에 같은 번호가 모두 있는 **완성된 쌍만** 사용하므로, 한쪽에만 점을 찍은
동안에는 화면이 바뀌지 않고, 짝의 한쪽을 지우면 그 쌍이 빠진 직전 상태로 돌아간다.
상태 표시줄에 현재 쌍 개수·사용 모델·inlier 수·RMSE(px)가 나온다. RMSE는 RANSAC이
고른 inlier 기준이며, 걸러진 점은 화면에서 outlier 색 마커로 표시된다.

정합점이 없을 때는 크기가 다른 영상이라도 작은 쪽을 큰 쪽 프레임에 맞춰
(가로세로 비율 유지) 확대해 겹치므로 절반만 겹치는 일이 없다. 정합점이 있을
때의 캔버스는 두 영상을 모두 담는 크기로 잡혀 기준 영상 밖도 잘리지 않는다.

### 오버레이 창 조작

정합 결과 창에는 밝기/대비 대신 정합 상태를 확인하기 위한 조작부가 있다.

- **영상1 / 영상2 불투명도**: 각 영상의 불투명도를 0~100%로 조절 (기본 50:50)
- **화면 맞춤(Fit)**: 켜져 있으면(기본) 영상을 항상 화면에 채워서 표시.
  직접 줌/패닝하면 자동으로 꺼지고, 다시 누르면 화면에 맞춘다
- **Points**: 정합점 마커 표시 on/off (기본 on)
  - 노란 십자 = 잔차 0(모델이 그대로 통과한 점, 번호 없음)
  - 초록 원 + 번호 + 잔차 = 잔차가 있는 올바른(inlier) 정합점
  - 빨간 원 + 번호 + 잔차 = outlier
- **Marker**: 마커/번호의 색상과 크기 설정
- **Flicker**: 지정한 간격(0.1~10초)으로 두 영상을 자동으로 번갈아 표시
- **Space 키**: 합성 → 영상1 → 영상2 순으로 직접 넘기기
- **마커 우클릭**: 그 정합쌍을 양쪽 창에서 삭제하고 남은 쌍으로 다시 정합

### 정합 후보 추천

창 2 툴바의 **후보 추천 토글**(기본 켜짐)을 켜 두면, 한쪽 창에만 찍힌 점의
예상 위치를 현재 정합 변환으로 계산해 **반대쪽 창에 점선 원**으로 표시한다.
원의 크기는 현재 정합 오차(RMSE)를 반영하므로, 원 안쪽에서 대응점을 찾으면 된다.
짝이 완성되면 그 후보 표시는 자동으로 사라진다.

### 사용법

#### 기본 조작
- **좌표 추가**: 마우스 왼쪽 클릭
- **좌표 삭제**: 마우스 오른쪽 클릭 (해당 좌표 근처에서)
- **정합쌍 삭제**: Ctrl+오른쪽 클릭 → 같은 번호의 점을 **양쪽 창에서** 함께 삭제
- **라벨 수정**: 기존 좌표 번호를 왼쪽 클릭하여 새 번호 입력
- **확대/축소**: 마우스 휠 스크롤
- **이미지 이동**: Ctrl+드래그 또는 중간 마우스 버튼 드래그
- **실행 취소**: Ctrl+Z

#### 툴바 기능 (모든 조작 버튼은 아이콘으로 표시되며, 툴팁으로 설명을 볼 수 있다)
- 📁 **Open**: 이미지 파일 열기
- 📍 **좌표와 함께 열기**: 이미지와 기존 좌표 데이터 동시 로드
- ➕ **Zoom In** / ➖ **Zoom Out**: 이미지 확대/축소
- 💾 **Save**: 좌표가 표시된 이미지 저장
- 📄 **좌표 저장**: 좌표 데이터를 텍스트 파일로 저장
- 🗑️ **전체 삭제**: 모든 좌표 삭제
- 🔢 **번호 순차화**: 빠진 번호를 메워 순서대로 다시 매김 (예: 1,3,4,6 → 1,2,3,4).
  두 창에 같은 매핑을 적용해 짝이 유지된다
- ❌ **Exit**: 프로그램 종료 (두 창을 함께 확인하고 한 번만 묻는다)
- ☀️ **밝기** / ◐ **대비**: 화면 표시 전용 조정 (숫자는 슬라이더 바로 옆)
- ↺ **Reset**: 밝기/대비 초기화
- 🎨 **Marker**: 정합점 마커/번호의 색상·크기 설정
- 🔗 **정합 (창 2)**: 정합점 5쌍 이상일 때 활성화, 정합 결과 창을 연다
- 🔴 **Live (창 2)**: 실시간 정합 오버레이 on/off
- ◎ **후보 추천 (창 2)**: 짝 없는 점의 예상 위치 표시 on/off (기본 on)

## 설치 및 실행

### 요구사항
- Python 3.10 이상
- 필요한 패키지:
  - PyQt6 >= 6.9.1
  - NumPy >= 2.2.6
  - Pillow >= 11.3.0
  - OpenCV-Python >= 4.11.0.86

### 설치
```bash
# uv 사용 (권장)
uv sync

# 또는 pip 사용
pip install -r requirements.txt
```

### 실행
```bash
python image_registration_tool.py
```

프로그램 실행 시 두 개의 창이 열립니다:
- Image Registration Tool 1
- Image Registration Tool 2
